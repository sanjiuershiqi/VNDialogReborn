# VNDialogReborn / VN 对话引擎重置版

本项目是 [VNDialog](https://github.com/YourZi/VNDialog) 的重制版，原作者 YourZi。原项目长期未维护，在 NeoForge 1.21.1 下部分功能已无法正常使用，因此有了 VNDialogReborn。

- 运行环境：Minecraft 1.21.1，NeoForge
- 当前版本：3.3.0
- 对话文件的写法与原作一致，基础用法参考原作链接；本项目新增的内容见下文。

## 游戏内编辑器

`/dialog editor` 打开。编辑器只读写 `config/vndialog_editor/` 下的文件，保存后自动执行 `/dialog reload`。3.0.0 重写了整个编辑器。

- **剧本**：一个节点一张卡片，按文件顺序排列，卡片底部显示接下来去哪里。
- **关系图**：查看大型剧本里节点之间的关系。
  - 拖动节点摆放，位置单独保存，不写进对话文件。
  - 从节点右侧的圆点拖出连线；拖到空白处会新建节点并连上。
  - 「所有文件」模式显示对话文件之间通过 `dialog show` 的调用关系。
- **舞台**：按游戏内的真实位置预览背景、立绘和对话框，可拖动、缩放立绘。
- **检查**：按游戏实际的播放方式检查对话，点一条提示会跳到对应节点。
  - 错误：跳转或选项指向不存在的节点、节点 ID 重复、起始节点不存在。
  - 警告：永远播不到的节点、无法结束的死循环、不会生效的跳转、空台词或空选项、缺少翻译、找不到背景/立绘/音频文件、物品不存在。
- **属性**：台词、走向、演出、逻辑四页。
  - 台词支持 `§` 格式代码和翻译键模式；切换到翻译键时原文会保留为备用文本。
  - 展示物品用图标网格选择，可从背包或全部物品里挑；点 ✎ 可设置名称、描述和附魔光效。
- 支持撤销/重做、多文件切换、试玩（▶）。界面缩放可在文件菜单里调整。

编辑器的代码结构见 [docs/EDITOR.zh-CN.md](docs/EDITOR.zh-CN.md)。

## 对话中的展示物品

- 鼠标悬停在对话展示的物品上，会显示物品提示（名称、描述、附魔等）。
- 物品的 `nbt` 写成 `{components:{...}}` 时会生成完整的自定义物品，例如：
  `{components:{"minecraft:custom_name":'"餐厅菜单"'}}`

## 新增的立绘动画

- `IMPACT`：立绘从旁边撞到中间；`IMPACT_MAX` 会一直撞到另一侧的立绘位置。
- `ROTATE`：原地旋转一圈。
- `REVERSE`：立绘倒挂着从屏幕上方出现。
- `FLASH`：屏幕闪两次白光。

## 对话中的按键

- 数字键 `1`–`9`：直接选择对应的选项，选项前会显示编号。
- 空格 / 回车 / 滚轮向下：和点击对话框一样，显示完整台词或进入下一句。
- 滚轮向上：打开历史记录。
- 右键 / `H`：隐藏对话框和按钮，只看背景和立绘；再按任意键或点击恢复。
- `Ctrl`：快进，遇到选项会停下。

## 对话设置

编辑器顶栏的「对话设置」（或 `F9`）里可以开关上面所有操作，改动立即生效，保存在 `config/vndialog_play.json`：

- 数字键选择选项、空格 / 回车推进、滚轮上下、右键 / `H` 隐藏对话框，都可以单独关掉。
- 已读记录可以整体关闭，也可以分别关掉「已读台词变色」「走过的选项变灰」「Ctrl 快进跳过未读」。
- 已读台词的颜色有八个预设可选，也可以在这里清除全部已读记录。

## 已读记录

模组会记住每个玩家读过哪些台词，保存在客户端的 `config/vndialog_read.json`，换服务器、重启游戏都还在。

- 读过的台词用较浅的颜色显示。
- 目标节点已经读过的选项显示为灰色，方便找没走过的分支。
- 客户端配置 `skipUnreadText` 设为 `false` 后，`Ctrl` 快进只跳过已读台词，遇到没读过的会停下。
- 已读台词的颜色由 `readTextColor` 控制；设成和 `dialogTextColor` 一样就看不出区别。
## 更新记录

### 3.3.0

- 新增「对话设置」界面（编辑器顶栏或 `F9`）：前面加的所有操作和已读显示都可以在这里开关，改完立刻生效。
- 已读台词的颜色改为可选项，加入了清除已读记录。
- 模组配置里不再重复提供这两项，统一由编辑器设置管理。

### 3.2.0

- 新增已读记录：已读台词变色、走过的选项变灰、可设置为只快进已读内容。
- 右键或 `H` 隐藏对话框；滚轮向下推进对话。
- 修复按 `Ctrl` 快进时会直接越过选项的问题。

### 3.1.0

- 对话中可用数字键选择选项，空格 / 回车推进对话。
- 编辑器「走向」页里每个选项可以设置选中后执行的命令和显示条件。
- 修复模组列表里的描述显示为乱码。

### 3.0.0

- 重写游戏内编辑器，删除旧编辑器代码。
- 新增关系图、与游戏一致的舞台预览、物品图标选择与自定义、对话检查。
- 对话中展示的物品支持悬停提示和自定义物品。
- 翻译键没有对应翻译时，显示台词里保存的备用文本，而不是键名。
